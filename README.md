## 1. Что за проект

`taskline` — консольная утилита для ведения списка задач. Задачи хранятся в одном
текстовом файле в домашней папке пользователя, работа идёт через команды терминала:
добавить задачу, отметить выполненной, посмотреть список.

Проект небольшой — около 400 строк на Python, один автор, последний коммит две недели назад.

## 2. Кто им пользуется

| Группа | Что ей нужно от документации |
|---|---|
| Обычный пользователь | Как установить и как выполнять базовые действия |
| Продвинутый пользователь | Полный список команд и флагов, формат файла хранения |
| Разработчик | Как запустить проект локально и как устроен код |

Основная аудитория — первая группа: утилита рассчитана на тех, кто работает в терминале,
но не обязательно умеет читать код.

## 4. Чего не хватает

Вопросы, на которые я не нашёл ответа при изучении проекта:

1. **Где хранится файл с задачами.** В коде путь собирается динамически, в README об этом
   ни слова. Пришлось искать в `storage.py`.
2. **Полный список команд.** В README показана только команда `taskline add`. Остальные
   я нашёл, прочитав `cli.py`: `list`, `done`, `remove`, `clear`.
3. **Что делать при ошибке `Permission denied`.** В задачах трекера
   ([issue #12](https://github.com/)) эта проблема упоминается
   дважды, но описания решения нигде нет.
4. **Формат файла хранения.** Непонятно, можно ли редактировать его вручную и что будет,
   если формат нарушить.

> Пункт 4 остался невыясненным до конца — в коде есть проверка формата, но её поведение
> при некорректных данных я определить не смог. Связаться с автором возможности нет.
